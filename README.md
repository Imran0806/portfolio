# Portfolio
# STRUCTURE DU PORTFOLIO :
## Le portfolio est constitué de 6 activités :
# Activité 1 :
## Description : 
Le but de cette activité est de tester le niveau en géomètrie des arrivants en 3ème secondaire selon les attendus du réferentiel de mathématiques du tronc commun (FWB)
## Fichier modalités :
Il énonce les différentes modalités de l'activité d'apprentissage, notamment :
- La durée de l'activité et son déroulement
- Le matériel nécessaire 
- Le niveau d'apprentisage et la matière dont il est question
## Fichier exercice :
Il s'agit simplement de l'épreuve en elle-même.
Elle consiste en un mot-croisés testant les connaissances des élèves en géomètrie
## Fichier correctif :
C'est là que se trouve la grille corrigées avec explication en dessous.
L'accent est mis sur les notions jugées importantes grâce à la mise en gras.
